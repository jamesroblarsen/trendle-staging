## Fonts, icons, and images

- **Fonts:** Cormorant Garamond (headings and the wordmark) and IBM Plex Sans (everything else), both under the SIL Open Font License 1.1, are bundled with the game through the @fontsource packages listed above. Their full licences are below.
- **Icons and images:** the favicon, the in-game icons (src/components/icons.tsx), the phone icons and the link-preview image (drawn by scripts/make-art.mjs) were all made for this project in code. The navy style follows the Fourth Meridian Games hub, also by the project owner. The hidden pixel mascot (Mascot.tsx) followed an earlier style kit supplied by the project owner; its reference sprite was used for direction only, and its artwork is not copied or shipped.
- **External requests:** the game loads nothing from other sites while playing. Source links open only if a player follows them.

## Other code and designs

- **Our World in Data Grapher:** no code from owid-grapher is used, and it is not a dependency. Charts are drawn by this project's own code. Only OWID's published data is used; see DATA_LICENSES.md.
- **Storyline (play.storylinegame.com):** no code or assets were copied. The site was not opened or inspected while building this project, and the design comes from a written brief.

## Unresolved, for human review

- The written brief asked for a visual style modelled on Storyline. Whether a similar look raises any trade dress or copyright question has not been assessed.
- No trademark search has been done for the name "Trendle".
- This repository has no licence of its own for its source code, so default copyright applies until one is chosen.
